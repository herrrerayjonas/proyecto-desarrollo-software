# Proyecto de Desarrollo de Software

## Introducción
Este proyecto tiene como propósito aplicar GitHub como herramienta para gestionar proyectos de desarrollo de software, facilitar el trabajo colaborativo y mantener un control organizado de los cambios realizados.

## Objetivo
Aprender a crear y administrar repositorios, organizar archivos, documentar avances y utilizar herramientas de colaboración digital.

## Herramientas utilizadas
- GitHub
- Navegador web
- Markdown
- Computador con conexión a Internet

## Actividades realizadas
1. Búsqueda y análisis de información sobre GitHub y control de versiones.
2. Creación y configuración del repositorio.
3. Carga y organización de archivos.
4. Comunicación mediante Issues, comentarios y commits.
5. Revisión del historial de cambios.
6. Aplicación de buenas prácticas de seguridad y colaboración.

## Estructura del proyecto
- README.md: documentación principal.
- documentos/: archivos del proyecto.
- evidencias/: capturas de pantalla de las actividades.

## Buenas prácticas
- Mantener los archivos organizados.
- Utilizar nombres claros.
- Proteger la información personal.
- Documentar los cambios.
- Respetar las contribuciones de los colaboradores.

## Conclusión
GitHub permite organizar proyectos, controlar versiones y facilitar el trabajo colaborativo mediante repositorios en la nube.
